TASK 11

The jQuery field guide.

Mini project: an accessible accordion menu. Open a topic to explore. Only one section stays open at a time.

A selector identifies DOM elements. Use #id for a unique element, .class for a group, or a tag name such as p.

Effects gradually change visibility. fadeIn and fadeOut animate opacity; slideDown and slideUp animate the visible height.

Chained animate calls run in order on each element. This queue lets you build a sequence of movements.

Each button handles a click event. The current panel uses slideToggle; the other panels use slideUp. aria-expanded stays synchronized with the visible state.
